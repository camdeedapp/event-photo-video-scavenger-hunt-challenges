# Camdeed Event Challenges 🎉  
**Creative scavenger hunt prompts and event challenge ideas for weddings, parties, and corporate events.**

Welcome to the official **Camdeed Event Challenges** repository — a curated collection of fun, interactive ideas designed to make any in-person event more engaging.

Camdeed is an **interactive event platform** that transforms photo-taking and guest participation into a **live scavenger hunt**. Guests complete custom photo and video challenges, earn points on a leaderboard, and see their moments appear instantly on a big screen — no app downloads required.
More information at [https://camdeed.com](https://camdeed.com)
